parte del codigo para la pagina de fredy reservar por que afecta todas las imagenes de la pagina 



img {
    width: 100%; /* Hace que la imagen ocupe todo el ancho del contenedor */
    height: auto; /* Mantiene la proporción original de la imagen */
    object-fit: cover; /* Recorta la imagen si es necesario para ajustarla bien */
    max-width: 200px; /* Tamaño máximo para que todas sean iguales */
    max-height: 200px; /* Altura máxima */
    display: block; /* Evita que haya espacios extra debajo de la imagen */
    border-radius: 10px; /* Bordes redondeados opcionales */
}
